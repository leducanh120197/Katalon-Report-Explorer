# Katalon-Report-Explorer
Katalon Report Explorer là một công cụ giúp bạn xem và quản lý báo cáo test Katalon một cách trực quan và thuận tiện hơn. Thay vì phải mở từng file trong thư mục báo cáo trên máy, ứng dụng cho phép bạn quét toàn bộ folder report, và hiển thị kết quả dưới dạng giao diện web, dễ theo dõi và thao tác.
